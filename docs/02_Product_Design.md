# Aleria AI Town Product Design

Version: v1.1

Last Updated: 2026-08-24

## Phase 1D implementation baseline

当前 MVP 的玩家不是可创建职业的完整 RPG 角色，而是固定 `default-player`。玩家可在曦谷的星辉酒馆、中央公园、晨曦城堡和低语森林之间旅行，观察三名 NPC、推进世界时间、对话，并完成“失踪的孩子”。下文的职业、关系、Memory 和更多地点属于产品演进设想。

# 1. Product Vision

## 1.1 Product Name

Aleria AI Town

## 1.2 Product Positioning

Aleria AI Town is an AI Native Fantasy Simulation Game.

项目定位：

不是传统网页游戏。

不是简单聊天机器人。

而是：

一个由 AI Agent 驱动的小型持续世界。

玩家进入一个幻想小镇，与具有独立人格、状态、目标和记忆的 NPC 共同生活。

核心理念：

> NPC不是等待玩家指令的角色，而是拥有自身生活轨迹的数字居民。

# 3. World Background

## 3.1 World Setting

世界名称：

Aleria（晨曦大陆）

背景：

多年以前，魔王战争席卷大陆。

战争结束后，大陆进入恢复时期。

大量冒险者、旅行者和居民来到曦谷。

这里成为：

-   冒险者交流中心
-   新故事发生地
-   不同角色相遇的地方

------------------------------------------------------------------------

## 3.2 Player Role

玩家身份：

冒险者。

玩家不是传统意义上的救世主。

而是：

进入这个世界，并逐渐认识居民、影响关系发展的外来者。

------------------------------------------------------------------------

# 7. NPC Character Design

## 7.1 Ryan

Identity:

年轻剑士。

Personality:

-   乐观
-   正义
-   热情

Public Goal:

成为真正的英雄。

Hidden Trait:

害怕史莱姆。

Behavior Pattern:

-   训练
-   帮助新人
-   与朋友交流

Example Dialogue:

玩家：

"你害怕什么？"

Ryan：

"英雄当然什么都不怕......不过史莱姆确实有点难处理。"

------------------------------------------------------------------------

# 7.2 Shir

Identity:

沉默刺客。

Personality:

-   冷静
-   内向
-   少言

Public Goal:

寻找属于自己的生活。

Hidden Trait:

喜欢甜食。

Behavior Pattern:

-   夜晚散步
-   买甜点
-   观察他人

Example Dialogue:

玩家：

"你喜欢什么？"

Shir：

"没什么。"

（停顿）

"......草莓蛋糕还不错。"

------------------------------------------------------------------------

# 7.3 Grey

Identity:

成年护卫。

Personality:

-   稳重
-   可靠
-   保护欲强

Background:

过去曾经无法保护重要的人。

Goal:

守护现在的伙伴。

Behavior Pattern:

-   巡逻
-   帮助居民
-   保护小镇

Example Dialogue:

玩家：

"为什么成为护卫？"

Grey：

"因为曾经有人需要我的保护，而我没有做到。"

------------------------------------------------------------------------

# 9. AI Native Features

## 9.1 Autonomous NPC

NPC根据：

-   Personality
-   State
-   Time
-   Location
-   Memory

生成行为。

------------------------------------------------------------------------

## 9.2 Persistent World

世界状态持续变化。

例如：

Day 1:

Ryan训练。

Day 2:

Ryan认识新的冒险者。

Day 3:

Ryan主动邀请玩家探索。

------------------------------------------------------------------------

## 9.3 Emergent Interaction

通过：

NPC之间关系

-   

记忆

-   

事件

产生非固定剧情。

------------------------------------------------------------------------

# 10. MVP Scope

# 11. Design Principles

## Character First

角色优先。

每个NPC必须具有：

独特人格。

------------------------------------------------------------------------

## Simulation First

模拟优先。

世界应该能够自主运行。

------------------------------------------------------------------------

## Simple But Expandable

简单但可扩展。

MVP保证闭环。

架构保留未来扩展空间。
