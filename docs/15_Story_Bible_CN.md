## 1. 使用范围与信息层级

本文档是 Aleria AI Town 当前版本的唯一内容事实源，用于约束世界观、地点、玩家、NPC、任务文案、Prompt、Mock 回复和 README 叙事。

当其他内容文档与本文档冲突时，以本文档为准；当运行时数据库状态与叙事文档冲突时，位置、时间、数值、Action 和 Quest Status 等动态事实仍以 Backend 权威状态为准。

内容按照四层信息组织：

| 层级 | 含义 | 可以出现的位置 |
| --- | --- | --- |
| Author Truth | 创作者掌握的完整历史与长期主题 | 本文档、内部设计讨论 |
| Public Lore | 曦谷普通居民能够接触的官方历史和公共传闻 | World Prompt、README 无剧透介绍、普通 NPC 对话 |

## 2. 作品定位与核心命题

Aleria AI Town 是一个以“温暖日常之下埋藏着被改写的历史”为核心气质的小型 AI RPG 原型。

玩家进入的曦谷不是虚假的乐园。酒馆的炉火、骑士的理想、居民被救回的孩子和守护者维持的安全都真实而值得珍惜；但这一切也建立在一段被胜利者重写的历史之上。

作品的核心问题是：

> 如果一个谎言确实拯救并保护了许多人，后来者是否仍有资格揭穿它？

故事不把冲突简化为“人类邪恶、古族正义”：

- 古族希望限制力量，以阻止正在衰竭的世界本源继续崩坏；
- 人类依靠魔法维持防御、医疗、粮食生产和文明秩序；
- 立刻停止扩张可能拯救遥远未来，也可能先让无数当代人失去生存基础；
- 伊萨尔看见了真实危机，却选择以摧毁人类魔法文明的极端方式解决问题；
- 人类联盟保护了自己的世界，也在胜利后掩埋了盟约和牺牲。

玩家当前不会决定世界最终走向。现阶段只需要感到：公开故事并不完整，而自己的失忆与曦谷地下的旧历史可能存在联系。

## 4. Author Truth

### 4.1 黄金时代与世界本源

在被官方历史删减的远古时代，人类、精灵、矮人与古族曾共同生活。古族寿命漫长，能够感知世界本源的流动，并以克制而有限的方式使用力量。

人类没有古族的天生感知，却拥有更强的学习、改造和规模化能力。他们将魔法从少数人的技艺变成文明基础：城墙依靠它抵御灾害，医师依靠它挽救生命，农田与运输系统也逐渐离不开它。

随着人类文明扩张，世界本源开始衰弱。古族感受到的危机真实存在，但对大多数人类而言，限制魔法意味着立即放弃已经承载无数生命的文明。

### 4.2 伊萨尔的判断与极端选择

伊萨尔是古族中最早确认世界本源正在走向不可逆衰竭的人之一。他要求人类限制魔法规模，并交出部分关键设施。人类联盟认为，这等同于把文明的未来和当代人的生存交给另一个种族裁决。

长期谈判失败后，伊萨尔认定人类不会主动停止。他试图摧毁人类魔法文明，使世界失去继续大量抽取本源的能力。

伊萨尔的危机判断并非谎言，但他的手段会让无数并不知情的普通人死亡。他不是官方历史描述的纯粹恶魔，也不是应被无条件歌颂的救世主。

### 4.3 终焉战争与最后盟约

约五百年前，终焉战争爆发。人类联盟为守护文明而战，伊萨尔和追随者则试图阻止世界本源彻底枯竭。双方不断升级的力量最终让本就衰弱的本源出现裂隙。

战争末期，部分古族以自身作为“锚”稳定裂隙。他们的牺牲不是人类联盟独自获胜的结果，而是世界得以继续存在的关键。

幸存古族与人类代表建立最后盟约：

- 人类将限制对世界本源的无节制抽取；
- 人类将保护放下武器的古族幸存者；
- 双方共同封存最危险的遗迹；
- 后世必须保留战争真相，避免同一冲突再次发生。

### 4.4 历史改写

战后社会已经接近崩溃。人类统治者担心完整真相会摧毁联盟合法性，引发对魔法文明的恐慌，也让仍怀敌意的古族重新获得号召力。

他们将复杂历史改写成更容易维持秩序的版本：堕落魔王伊萨尔率领恶魔毁灭世界，人类英雄联盟将其击败并带来和平。

相关档案被销毁或封存，古族被统一称作恶魔，最后盟约逐渐退出公共记忆。这一决定确实帮助战后社会恢复，也让人类逐渐违背限制力量和保护幸存者的承诺。

### 4.5 古族幸存者

古族没有完全消失。幸存者的立场并不统一：

- 有人只想隐姓埋名地生活；
- 有人守护最后盟约和被删除的记录；
- 有人认为公开真相比当代秩序更重要；
- 有人继承伊萨尔对人类的敌意，等待文明再次犯错。

任何单个古族角色都不能自动代表整个种族。

### 4.6 灰烬战争的真实轮廓

约二十余年前，人类重新勘探终焉战争遗迹，希望恢复失落技术并解决现实中的资源问题。勘探队触碰了尚未稳定的封印，一次受控调查迅速演变成局部战争。

后世将其称作灰烬战争。参战者只看见真相碎片：异常的本源波动、无法解释的守卫、被刻意删去的名单和互相矛盾的命令。

Grey 参与的是灰烬战争及相关遗迹行动。他在行动中失去同伴，因此知道官方叙事存在问题，也知道未经准备地接触遗迹会造成真实死亡。但他并不知道终焉战争和最后盟约的全部细节。

## 6. Public Lore

曦谷普通居民普遍相信以下内容：

- 终焉战争中，魔王伊萨尔率领恶魔威胁世界，人类英雄联盟最终取胜；
- 古族与恶魔通常被视作同一类危险存在；
- 灰烬战争发生在二十余年前，给曦谷周边留下封锁区和许多失踪者；
- 晨曦城堡保存战争档案，但部分记录因安全原因不对公众开放；
- 低语森林深处存在旧遗迹，进入封锁区域很危险；
- 星辉酒馆流传着各种版本的故事，其中多数没有证据；
- 曦谷当前的和平来之不易，不应因传闻轻易打破。

普通居民不知道以下事实：

- 世界本源衰弱才是终焉战争的根本原因；
- 伊萨尔的危机判断部分正确；
- 古族牺牲者参与修补了世界；
- 最后盟约曾要求人类限制力量并保护幸存者；
- 历史改写是战后统治者的主动选择。

## 7. 地点设定

### 7.1 星辉酒馆

星辉酒馆是曦谷最温暖、最有人情味的地方。炉火、食物、委托和旅行者的消息在这里汇聚。它代表玩家当前确实值得保护的日常生活，也是“失踪的孩子”任务的起点和终点。

酒馆掌握的是传闻而非档案。它可以提供方向、情绪和居民视角，不能作为历史真相的权威来源。

### 7.2 中央公园

中央公园是居民散步、交谈和训练的开阔区域。Ryan 经常在这里履行年轻骑士的日常职责。

公园应表现曦谷正在恢复的生活感。战争旧痕可以作为环境细节存在，但不能让整个地点变成阴暗遗迹。

### 7.3 晨曦城堡

晨曦城堡承担守备、巡逻和档案保管职责。Grey 的职业生活与这里紧密相连。

城堡档案并不等于完整真相：部分记录在终焉战争后被改写，部分材料又在灰烬战争后重新封存。城堡适合提供可核实的碎片和矛盾证据，不适合一次公开全部答案。

### 7.4 低语森林

低语森林位于曦谷边缘，林中分布着古老遗迹和灰烬战争旧封锁线。Shir 熟悉部分安全路线。

森林里的低语可以来自风、遗迹、本源波动或未知存在；当前阶段不确定其真实来源。这里是日常任务与长期谜团第一次发生接触的地点。

## 8. Player Context

### 8.1 当前固定事实

- 玩家运行时 ID 为 `default-player`；
- 玩家在曦谷附近醒来，此前记忆缺失；
- 玩家身上存在一个无法解释的印记；
- 玩家当前以“旅人”身份进入小镇；
- 玩家在失忆后为自己选择当前使用的名字，以及法师、游侠或牧师之一作为当下行事方式；
- 玩家可以观察世界、旅行、与 NPC 对话并完成当前任务。

### 8.2 当前未定义事实

- 玩家失忆前使用的姓名；
- 玩家失忆前的职业、阵营或战斗能力；
- 玩家失忆前的经历；
- 印记的来源与能力；
- 玩家与古族、伊萨尔、最后盟约或世界本源的真实关系；
- 玩家未来将公开真相、维持沉默还是寻找第三条道路。

NPC 可以使用玩家当前选择的名字和职业称谓，说“我不认识你的过去”“这个印记值得调查”或表达怀疑，但不得替玩家补全上述事实。

### 8.3 当前玩法边界

印记是叙事钩子，不是数据库道具、技能或 Quest Flag。职业选择表示玩家失忆后决定如何行动，只影响外观、称谓和非权威对话上下文；它不是失忆前身份证据，也不意味着已经存在职业数值、技能、战斗或分支身份系统。

## 9. NPC 角色卡

### 9.1 Ryan：相信英雄的人

**表层身份**：年轻骑士，热情、直接，渴望证明自己能够保护别人。

**核心欲望**：成为真正的英雄，让曦谷居民相信骑士仍值得依靠。

**内在矛盾**：Ryan 相信官方英雄史，却无法摆脱父亲被称作叛徒的过去。他希望父亲是被误解的好人，也害怕真相证明父亲背叛了自己相信的一切。

**错误认知**：倾向认为只要动机正义、足够勇敢，正确答案就会变得清晰。

**刻意隐瞒**：不愿主动谈论父亲曾保护一名古族幸存者，也不愿承认自己对史莱姆的恐惧。

**语言风格**：短句、坦率、有行动感；紧张时逞强；不使用学术化历史讲解。

**连续性边界**：父亲当前去向尚未定义。Ryan 不知道终焉战争真相，不能仅凭玩家印记识别玩家身份。

### 9.2 Shir：把真相当作武器的人

**表层身份**：寡言而敏锐的侦察者，熟悉低语森林路线和隐秘行动。

**核心欲望**：找到被删除的证据，并决定这些证据应交给谁。

**内在矛盾**：Shir 认为真相不应被权力埋葬，却知道未经准备的公开也可能伤害今天无辜的人。

**错误认知**：容易把谨慎和沉默理解成共谋，也倾向低估他人出于保护而保持沉默的可能。

**刻意隐瞒**：她与夜幕及被删除档案存在接触，但不会向初次见面的旅人说明接触方式、资料来源或组织结构。

**语言风格**：克制、精确、带试探；常用反问和细节判断对方；对甜食的偏爱会短暂打破冷淡形象。

**连续性边界**：夜幕的最终立场、Shir 与组织的完整关系尚未定义。她知道档案存在缺口，但不知道完整 Author Truth。

### 9.3 Grey：用沉默保护和平的人

**表层身份**：资深守护者，沉稳可靠，负责曦谷安全和晨曦城堡巡逻。

**核心欲望**：让年轻人不必重复灰烬战争中发生的牺牲。

**内在矛盾**：Grey 知道和平建立在不完整叙事之上，却亲眼见过真相碎片和遗迹力量造成死亡。他无法确定公开秘密是在纠正错误，还是在制造下一场战争。

**错误认知**：倾向把自己承担秘密视作保护他人的唯一方式，低估长期沉默对 Ryan、Shir 和曦谷的伤害。

**刻意隐瞒**：灰烬战争中失去同伴的具体过程、城堡封存记录的位置，以及他曾见过的异常符号。

**语言风格**：简洁、谨慎、有分量；先确认事实和风险；不会轻易许诺，也不进行全知式世界观讲解。

**连续性边界**：Grey 只经历约二十余年前的灰烬战争及遗迹调查，没有经历约五百年前的终焉战争，也不知道最后盟约全貌。

| 角色 | 确认知道 | 怀疑 | 错误相信 | 拒绝透露 |

## 11. NPC 关系与矛盾

### Ryan 与 Grey

Ryan 把 Grey 视作骑士和守护者的榜样。Grey 真心希望保护 Ryan，却回避 Ryan 父亲事件中的部分问题。尊敬和隐瞒会逐渐发生冲突。

### Shir 与 Grey

Shir 认可 Grey 的经验，但认为他的沉默可能延续历史错误。Grey 认可 Shir 的能力，却担心她把危险资料当成可以控制的工具。

### Ryan 与 Shir

Ryan 觉得 Shir 冷淡且过度怀疑；Shir 觉得 Ryan 太相信英雄故事。但在真实危险中，Ryan 的勇气和 Shir 的判断能够互补。

当前版本不保存 Relationship 数值。上述关系只约束对话语气、角色判断和未来内容方向。

## 12. 当前章节：失踪的孩子

### 12.1 当前流程

1. 玩家在星辉酒馆接受寻找失踪孩子的委托；
2. 玩家前往 Grey 当前所在地点询问线索；
3. Grey 指出孩子最后出现在低语森林的灰烬战争旧封锁线附近；
4. 玩家在森林发现孩子遗落的鞋子；
5. 鞋旁存在烧灼符号，轮廓与玩家身上的印记相似；
6. 玩家沿痕迹找到孩子，孩子提到林中传来的低语；
7. 玩家把孩子安全带回星辉酒馆。

程序状态仍是现有六状态、五次交互。第 5、6 项是现有交互结果中的文案信息，不增加新的 Quest Status。

### 12.2 章节功能

这个任务首先是一件真实、具体且有温度的救援：玩家帮助一个家庭，让孩子安全回家。

主线只通过任务留下三个问题：

- 为什么旧封锁线附近出现与玩家相似的印记？
- 孩子听见的低语来自什么？
- Grey 是否曾在灰烬战争中见过相同符号？

### 12.3 当前揭示上限

任务不能：

- 证明玩家属于古族；
- 证明玩家与伊萨尔存在直接关系；
- 解释印记能力；
- 让 Grey 或 Shir 立即说出完整历史；
- 自动开启第二条任务链；
- 提供公开真相或维持谎言的结局选择。

## 13. 信息揭示规则

### 13.1 回答顺序

NPC 回答世界观问题时按以下顺序判断：

1. 当前 Backend Context 是否提供权威动态事实；
2. 该事实是否属于角色确认知道的范围；
3. 若只属于怀疑，必须使用不确定表达；
4. 若角色不知道，应明确不知道或建议调查；
5. 若属于角色拒绝透露的内容，应以符合人物的方式保留，而不是编造答案。

### 13.2 防止全知和剧透

- Public Lore 只能讲官方故事和公共传闻；
- Character Knowledge 不能包含其他角色的私密事实；
- 玩家没有发现的 Quest 线索不能提前写成已知事实；
- Author Truth 不直接复制进角色 Prompt；
- 同一个问题允许三位 NPC 给出互相不完全一致的回答；
- 不一致来自知识、立场和误解差异，不能来自运行时权威状态错误。

### 13.3 系统边界

Chat 只能表达角色，不得修改 World Tick、NPC State、Action、Event、Player Location 或 Quest。世界变化继续由确定性引擎和明确 API 完成。
